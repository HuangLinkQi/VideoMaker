## 视频提示词最小规则（摘自 22 套，agent 逐场生成时必须遵守）

- 先锁定剧本原文：不增删改对白，不重写剧情。
- 每场一条提示词，写入 `state.json` 对应场景的 `prompt` 字段。
- 抽象情绪必须转译成可见行为（视线落点、手部任务、呼吸、语速），不写「紧张/难过」光杆词。
- 运镜要有叙事作用并写清幅度、方向、停止点；人物动作复杂时摄影机保持稳定。
- 接触动作用「触发—反应—结果—释放」闭环，不留僵持姿势。
- 素材状态写清持有者与可见状态（如：旧手机屏幕碎裂、在王桂芬手中）；易串用道具正面声明禁区。
- 每条片段结尾写清离开状态（人物位置、道具去向），供下一场衔接。
- 详细规则读 `22剧本转视频提示词/Gaven剧本转视频提示词_SKILL_单文件完整版.md`；细化运镜/表演/连续性时读其 `references/` 下对应文档。
