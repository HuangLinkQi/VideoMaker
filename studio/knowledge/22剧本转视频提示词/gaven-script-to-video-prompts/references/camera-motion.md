# 镜头运动设计

## 内部判断顺序

1. 提取整段戏剧节点：目标、主动权、关键动作、关系变化和结尾状态。
2. 设计整段运动曲线：何时跟随行动、何时固定观察、何时靠近关系、何时停止承接反应。
3. 为每个镜头选择唯一主要运动方式。
4. 回看整段的运动密度、方向、轴线、速度和停止点。

不要逐镜孤立添加“电影感”运镜。常用曲线是：运动建立行动 → 固定看清冲突 → 轻推强调变化 → 停住承接反应。

## 逐镜问题

选择运镜前依次判断：

- 主体是否位移？需要保留主体与目标的空间关系时使用稳定跟拍或横移。
- 注意力是否在同一空间内转移？小幅摇摄可以连接对象；关键手部或物件通常直接切近更清楚。
- 人物关系是否变化？外部动作少而心理距离变化时，才使用缓慢推近、拉远或小幅环绕。
- 固定镜头是否已经足够？足够时删除装饰性运动。

## 运镜功能

- 固定镜头：对白、停顿、尴尬、喜剧节奏、关键接触和听者反应。
- 稳定跟拍：进入场景、走向目标、行动方向明确的位移。
- 小幅横移：展示人物与空间或两人站位关系。
- 轻微摇摄：在同一空间内转移注意力或跟随转身。
- 缓慢推近：意识变化、关系靠近、重要决定；必须有停止点。
- 轻微拉远：关系疏离、失败、沉默结束或环境重新占据画面。
- 小幅环绕：关系或力量结构发生明显改变；对白戏谨慎使用。
- 轻微手持呼吸感：即时、不确定或轻度慌乱；不得变成剧烈抖动。

## 组合限制

- 一个镜头只保留一个主要运动，不同时堆叠推、拉、摇、移和环绕。
- 连续镜头不要重复同方向、同速度的推近。
- 人物动作复杂时优先固定或稳定短跟拍。
- 重要台词落点、笑点和反应时让摄影机停止或保持稳定。
- 写清运动对象、方向、幅度和停止条件，不只写一个术语。
- 运动方向必须兼容人物左右位置、视线和对话轴。

## 全段复核

- 是否每个运动都带来新信息、空间变化或心理距离变化？
- 是否连续多个镜头都在运动，造成漂移和疲劳？
- 是否有重要反应被运镜遮盖？
- 是否存在主体运动和摄影机运动互相打架？
- 是否能把任一装饰性运动改为固定镜头而不损失表达？可以则改为固定。
