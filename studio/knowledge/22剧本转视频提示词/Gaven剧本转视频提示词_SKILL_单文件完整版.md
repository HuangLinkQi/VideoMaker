# Gaven 剧本转视频提示词

把定稿剧本编译为 Seedance 2.5 可直接使用的精简提示词。默认人物、场景、服装和道具已经准备并接入。内部完成剧情拆分、运镜设计、表演转译和连续性判断；默认只向用户交付最终提示词，不展示分析、推理、备选方案或制作解释。

## 固定默认值

- 默认模型为 Seedance 2.5，单条视频最长30秒；按对白和动作选择实际时长，不机械填满。
- 不写画幅、分辨率、模型名称或平台参数。
- 默认逐镜标注时长；只有用户明确要求不要逐镜时长时，才只写总时长。
- 每个镜头写明镜头编号、景别、运镜、时长和画面动作；各镜头时长之和必须等于片段总时长。
- 默认保留原对白，不增词、不改词、不自动加字幕。
- 默认无背景音乐，只保留对白、动作声和环境声；用户另有要求时覆盖。
- 默认只输出最终提示词。用户明确要求解释设计、分析运镜或诊断样片时，才展示相应分析。

## 输入前提

把用户已经接入的素材视为锁定资产，不重新设计：

- 人物图负责身份、脸型、五官、肤色、发型和当前基础服装；
- 场景图负责空间、陈设、机器位置、材质和光线；
- 服装或道具图只负责对应物件，不自动穿到人物身上；
- 用户说明的图片编号和职责必须原样保留。

没有素材编号时，不虚构“图片1、图片2”。只用角色名和道具名描述。

## 内部工作流程

1. 锁定剧情、对白、人物关系、动作结果和片段结尾，不擅自改写。
2. 按动作因果、对白容量和关系转折拆成最长30秒的片段；高密度对白、复杂接触、身份揭晓或多人动作优先拆开。
3. 为整段建立戏剧节拍：人物目标、主动权变化、关键动作、关系变化和结尾情绪。
4. 先设计整段摄影运动曲线，再决定各镜头景别与运镜；完成后复核运动密度、方向、轴线和节奏。需要细化时使用本文件后部的【镜头运动设计详则】。
5. 只激活本段实际出场的素材，并记录可见状态、持有者、位置和使用禁区。
6. 把抽象情绪编译成可观察的面部、眼神、呼吸、手部、重心、动作和声音行为。
7. 为每个接触动作写清触发、反应、结果和释放；不得让人物保持拦、抓、按、挡等僵硬姿势继续长对白。
8. 按镜头编号输出，并分配足够的动作、台词和反应时间；时长总和必须匹配片段总时长。
9. 只保留当前片段最容易出错的一到三项关键锁定。
10. 直接输出可复制文本，不展示以上判断过程。

## 视觉风格

在【镜头】前写一次全段视觉风格，不在每个镜头重复。根据剧本与用户参考描述：

- 摄影媒介或胶片质感；
- 镜头焦段与景深倾向；
- 光线来源、色彩层次和画面质感；
- 故事类型、情感距离和整体气质。

示例：

> 柯达Portra 800胶片质感，柔焦，画面边缘轻微虚化，复古怀旧，具有浓郁故事感。35mm镜头，f/1.8，浅景深。暖色室内灯光与窗外夜色形成冷暖层次。亲密但尚有距离的都市爱情轻喜剧，人物表演自然克制。

用户已经给出视觉母版时，以用户版本为准；不要擅自叠加冲突风格。

## 镜头与运镜

先全盘考虑，再逐镜决定，最后全盘复核：

1. 先确定整段从建立空间、发生行动、看清冲突到关系变化的摄影节奏。
2. 再问每个镜头是否需要跟随位移、转移注意力、揭示信息、改变心理距离或观察反应。
3. 固定镜头已经能够清楚表达时，优先固定；不使用无叙事作用的装饰性运动。
4. 一个镜头只设置一个主要运动方式，并写清幅度、方向、跟随对象和停止点。
5. 人物动作越复杂，摄影机越稳定；人物外部动作少而关系发生变化时，才考虑轻微推近、拉远或小幅环绕。

每个镜头必须明确运镜状态，例如：固定镜头、稳定短跟拍、缓慢推近、轻微拉远、从左向右小幅横移、跟随转身轻微摇摄、小幅环绕、轻微手持呼吸感。不要只写术语，应写成可执行描述：

> 镜头从左向右小幅横移，稳定跟随林夏走向烘干机，同时保持目标机器位于画面右侧，到她停在机器前时镜头停止。

对话轴和人物左右关系保持稳定。注意力从人物转向手部、物件或动作结果时，优先明确切镜，不用快速推拉代替观察。重要笑点、尴尬停顿和听者反应出现时，让摄影机稳定下来。

## 动作与空间

关键动作使用“触发—反应—结果—释放”闭环：

> 两只手几乎同时按住门把。林夏说“松手”，周宇回答“女士优先”。林夏刚把手移开，周宇立即拉开门，同时将另一只手里的白衬衫送向滚筒入口，明确准备抢先放进去。林夏抬手挡住衬衫去路；短暂对视后双方自然收回手，不保持僵持姿势。

动作可能有多种解释时，不解释心理，而是补一个可见的下一动作，让意图明确。不要只写“争抢”“阻止”“犹豫”等概括词。

人物进入场景时写清目标方向与确认速度。若人物本应知道目标位置，写成快速扫视并立即锁定，不让人物长时间寻找或朝错误方向移动。

控制物理强度，避免模型把状态放大。例如写“衣物潮湿、有重量感，但不滴水”“动作急而不慌乱”“接触短暂，不发展成扭打”。

## 表演转译

不要只用“紧张、害羞、尴尬、心动、难过”等抽象情绪词。若使用情绪词，必须紧接模型可见或可听的表现：

> 她明显紧张起来，握住手机的双手微微收紧，视线在对方脸上停留半秒又移开，吸气后才开口。

优先使用：视线落点、眨眼与停顿、嘴角和下颌变化、肩颈张力、手部任务、身体重心、呼吸、语速、音量和尾音。表演必须由台词、动作、物件或对方反应触发，不堆独立微表情。

每段【表演】说明人物目标、策略、对白节奏和倾听方式：

- 未说话者持续倾听，反应先于回答，不产生说话口型；
- 玩笑像临时想到，不等待笑声；
- 笑点落下后留出对方短反应，再进入下一句；
- 对白期间安排少量有目的的生活动作，但每个节拍只保留一个主要动作；
- 不让人物冻结等待，也不让人物持续摸头、耸肩或挥手。

需要复杂情绪转折或多人互动时使用本文件后部的【人物表演与对白详则】。

## 素材状态与防串用

【素材状态】不仅说明素材职责，还要写当前可见状态：谁持有、放在哪里、是否穿着、是否在容器内、是否启用。例如：

```text
图片2锁定周宇身份及当前黑色T恤、黑裤；不得换装。
图片4仅作为周宇手中潮湿白衬衫道具，领口、门襟和一只袖子可辨认，不滴水，绝不穿到周宇身上。
```

画布中未出场素材默认不提；确有串用风险时写“本段不出现”。服装或道具首次出现时给出可识别锚点，避免白衬衫变成毛巾、裙子变成毯子。道具完成任务后写清去向，不让它突然消失或重新出现。

容易串用时必须正面声明：

- 独立服装图可能被穿到人物身上；
- 道具与人物服装属于同一品类；
- 多张人物图可能交换身份或服装；
- 场景图与人物图的光线、站位或服装不一致。

## 连续性

每条片段在最后一个镜头中写清离开状态：人物左右位置和姿态、关键道具位置及持有者、门的开合、机器是否运转、人物视线或未完成动作。下一条从这个物理结果开始，不重复上一条已经完成的事件。

需要跨片段检查时使用本文件后部的【连续性与质量检查详则】。

## 默认输出格式

```text
【Clip 01｜总时长26秒】

【素材状态】
只写当前片段实际使用的素材、可见状态和必要禁区。

【视觉风格】
写一次全段摄影质感、光线色彩、焦段景深、类型气质和人物情感距离。

【镜头】
镜头1，中近景，稳定短跟拍，时长3秒：
画面、空间方向、人物动作和必要对白。

镜头2，手部近景，固定镜头，时长2秒：
关键动作的触发、接触和结果。

镜头3，双人中景，缓慢推近，时长4秒：
人物互动、对白、听者反应及动作释放。

【表演】
人物目标、策略、可见的情绪动作、对白节奏和倾听反应。

【声音】
对白、关键动作声和环境声。默认无背景音乐。

【关键锁定】（仅在前文仍无法避免歧义时使用）
只补本段最容易出错的一到三项，不重复前文。
```

多条片段依次输出 Clip 01、Clip 02。用户要求“只给提示词”时，连开场说明都省略。用户明确要求不要逐镜时长时，保留镜头编号、景别和运镜，仅省略每镜时长。

## 样片返修

用户提供样片时，先查看完整视频和关键帧，内部按时间线比较“预期画面—实际结果—提示词歧义”，再只修改导致问题的片段。除非用户要求分析，否则直接给修订后的最终提示词。

- 进场方向错误：明确入口、目标方向、视线落点和确认速度。
- 服装或道具串用：强化素材状态、可识别锚点和“绝不穿着”。
- 物理状态夸张：限制滴水、抖动、奔跑、争抢等强度。
- 动作意图含混：补能显示目的的下一动作。
- 接触后僵持：补完成态、松手和重新站位。
- 人物贴太近：锁定距离、站位和接近上限。
- 对白错位：减少同镜说话人，明确一句一人、非说话者闭口倾听。
- 表演机械：补人物目标、手上任务、触发、听者反应和回答前停顿。
- 镜头单调：根据新观察内容增加必要切镜，不靠持续运镜制造变化。
- 镜头漂移：明确固定状态、运动幅度、方向和停止点。

不要因为一次失败重写全部视觉设定，也不要用不断增加禁止项掩盖动作结构问题。

## 最终检查

- 是否默认只输出最终提示词，没有暴露内部分析？
- 每条是否不超过30秒？各镜头时长之和是否等于总时长？
- 每个镜头是否包含编号、景别、运镜、时长和可执行画面？
- 【视觉风格】是否位于【镜头】之前且没有逐镜重复？
- 抽象情绪是否已经转译为可见或可听行为？
- 运镜是否有叙事作用、明确幅度与停止点，并保持轴线和方向？
- 复杂人物动作时摄影机是否足够稳定？
- 接触动作是否包含触发、反应、结果和释放？
- 素材职责、当前状态、可识别锚点和道具去向是否清楚？
- 原台词、说话者、口型与倾听反应是否正确？
- 片段结尾是否足以衔接下一条？
- 是否删除无用素材、通用限制、重复锁定和解释？

## 镜头运动设计详则

### 内部判断顺序

1. 提取整段戏剧节点：目标、主动权、关键动作、关系变化和结尾状态。
2. 设计整段运动曲线：何时跟随行动、何时固定观察、何时靠近关系、何时停止承接反应。
3. 为每个镜头选择唯一主要运动方式。
4. 回看整段的运动密度、方向、轴线、速度和停止点。

不要逐镜孤立添加“电影感”运镜。常用曲线是：运动建立行动 → 固定看清冲突 → 轻推强调变化 → 停住承接反应。

### 逐镜问题

选择运镜前依次判断：

- 主体是否位移？需要保留主体与目标的空间关系时使用稳定跟拍或横移。
- 注意力是否在同一空间内转移？小幅摇摄可以连接对象；关键手部或物件通常直接切近更清楚。
- 人物关系是否变化？外部动作少而心理距离变化时，才使用缓慢推近、拉远或小幅环绕。
- 固定镜头是否已经足够？足够时删除装饰性运动。

### 运镜功能

- 固定镜头：对白、停顿、尴尬、喜剧节奏、关键接触和听者反应。
- 稳定跟拍：进入场景、走向目标、行动方向明确的位移。
- 小幅横移：展示人物与空间或两人站位关系。
- 轻微摇摄：在同一空间内转移注意力或跟随转身。
- 缓慢推近：意识变化、关系靠近、重要决定；必须有停止点。
- 轻微拉远：关系疏离、失败、沉默结束或环境重新占据画面。
- 小幅环绕：关系或力量结构发生明显改变；对白戏谨慎使用。
- 轻微手持呼吸感：即时、不确定或轻度慌乱；不得变成剧烈抖动。

### 组合限制

- 一个镜头只保留一个主要运动，不同时堆叠推、拉、摇、移和环绕。
- 连续镜头不要重复同方向、同速度的推近。
- 人物动作复杂时优先固定或稳定短跟拍。
- 重要台词落点、笑点和反应时让摄影机停止或保持稳定。
- 写清运动对象、方向、幅度和停止条件，不只写一个术语。
- 运动方向必须兼容人物左右位置、视线和对话轴。

### 全段复核

- 是否每个运动都带来新信息、空间变化或心理距离变化？
- 是否连续多个镜头都在运动，造成漂移和疲劳？
- 是否有重要反应被运镜遮盖？
- 是否存在主体运动和摄影机运动互相打架？
- 是否能把任一装饰性运动改为固定镜头而不损失表达？可以则改为固定。

## 人物表演与对白详则

### 目录

1. 表演最小模型
2. 倾听与潜台词
3. 情绪转换
4. 多角色
5. 对白与声音

### 表演最小模型

每个有表演任务的人物明确：当前目标、障碍、代价、策略、身体状态和手上任务。把抽象情绪转成可观察行为：眼神、面部张力、头肩、手部、重心、呼吸、语速和音量。不要只写“紧张、害羞、尴尬、难过、心动”；若保留情绪词，必须紧接至少一个可见动作和一个声音或节奏信号。

远景和功能镜头只保留可读的大动作；近景和关系转折才增加微表情。不要让每个镜头都承载精细眼泪、指尖颤动和复杂呼吸。

### 倾听与潜台词

反应在对方说完前开始：人物先接收到信息，视线或呼吸改变，形成判断，再回答。不要让非说话角色冻结等待台词结束。

台词与真实目的不一致时，用主策略控制全身，只让潜台词从一个或两个部位泄露。例如嘴上拒绝而身体不退、保持微笑但手指收紧、语气强硬而尾音变软。

### 情绪转换

使用：原状态残留 → 触发 → 新旧信号争夺 → 新状态接管。触发必须可见可听，例如物件接触、一句台词、提示音、吞咽、眨眼或确认动作。

强事件的呼吸、泪痕、肌肉张力和身体余波必须进入下一镜。不要在切镜后瞬间恢复中性。

### 多角色

每个节拍明确主动者和反应者：

```text
A行动或说话 → B接收并判断 → B发生可见变化 → B回应 → A受到影响
```

避免所有角色同步大动作。对话镜头记录视线对象、肩线方向、距离和谁控制关键物件。需要精确口型时减少同一单元的说话角色和台词密度。

拦、抓、按、挡、握手等接触动作只维持剧情需要的短节拍。动作结果成立后，明确松手、收回手、放下物件或重新站位，不让人物保持僵硬姿势完成后续长对白。

### 对白与声音

只使用剧本确认台词。写明说话者、音量、语速、停顿、呼吸和口型要求。不说话时不生成清晰说话口型。

声音按优先级组织：对白可懂度、关键动作拟音、环境空间、音乐。音乐不能覆盖信息和重要呼吸。环境声和画外声必须有明确来源，不借声音偷偷新增实体角色。

## 连续性与质量检查详则

### 目录

1. 连续性账本
2. 硬错误
3. 语义审查
4. 常见失败
5. 返修原则

### 连续性账本

跨镜跟踪：人物身份与认知、关系状态、服装、发型、妆伤、身体状态、物件启用状态、所有者和所在手、站位、朝向、视线、运动方向、门和机器状态、时间、天气、主光方向、环境声和音乐状态。

每个镜头与生成单元都必须有进入和离开状态。下一项的进入状态必须兼容上一项的离开状态；时空跳转除外，但必须明确标记。

### 硬错误

- 镜头ID或单元ID重复；
- 镜头总时长不等于场次成片时长；
- 单元引用不存在的镜头；
- 专业镜头被多个单元重复完整覆盖或完全漏掉；
- 单元生成时长小于成片取用时长；
- 人物、道具、方向或对白出现显式矛盾；
- 下一单元进入状态无法继承上一单元结束状态。

### 语义审查

- 镜头是否带来新信息、关系变化或必要观察角度？
- 表演是否服务人物目标与策略？
- 运镜是否有原因和停止点？
- 多镜头单元是否重新锚定空间？
- 光线是否有可见来源并保持方向？
- 动作是否符合质量、惯性、接触和重心？
- 接触动作完成后是否释放，人物是否恢复到能自然继续表演的姿态？
- 抽象情绪是否已经转成模型可观察的表情、动作、呼吸或声音变化？
- 声音是否跟随事件且没有新增剧情事实？
- 提示词是否过载，是否能通过拆分降低风险？

### 常见失败

#### 按台词逐句切镜

保留说话者与倾听者的反应链，根据策略变化而非标点切镜。

#### 所有镜头等时长

按照信息所需时间和动作完成时间重设，不让模型默认时长控制剪辑节奏。

#### 只有镜头术语，没有人物行为

先写人物目标、动作和反应，再写摄影机如何观察。

#### 每镜都推拉摇移

删除不改变信息或心理距离的运镜，让主体和环境运动承担变化。

#### 提示词堆满全片设定

只保留当前单元有效角色、状态、素材、声画和局部风险。

#### 跨段重新表演同一动作

上一单元完成动作，下一单元从物理结果开始；只预留剪辑余量，不重复完整事件。

#### 人物切镜后情绪归零

继承呼吸、泪痕、张力、身体余波和未完成手势。

### 返修原则

只修改产生问题的镜头、单元及其直接接口。若问题来自原剧本，标记并返回剧本层；若来自镜头设计，修镜头流；若来自模型复杂度，拆生成单元；不要用加长负面提示词掩盖结构错误。
